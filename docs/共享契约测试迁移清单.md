# 共享契约测试迁移清单

本清单逐项登记迁移前两个入口中的 doctest 用例及终态归属。合并用例指向同一共享正文；拆分用例列出全部终态正文。原有条件用例保留能力守卫。

源码基点：`ab093d9`。共登记 C++23 入口 211 项、兼容入口 189 项源码用例，包含条件编译项。实际注册数量随语言标准与平台能力变化；验收结果见[共享双版本契约测试方案](共享双版本契约测试方案.md#10-实施结果与验收记录)。

## 默认引擎公共契约

默认引擎的共同公开契约维护在 `tests/common/default_engine_contracts.hpp`，套件名称为 `公共/基础/默认引擎`。生产配置由 `tests/default_engine/test_default_engine_cpp17.cpp`、`test_default_engine_cpp23.cpp` 装配，熵源 hook 配置由既有两个故障入口装配；四个目标链接 `tests/default_engine/default_engine_cross_translation_unit.cpp`。可复用声明和参数位于 `tests/fixtures/default_engine.hpp`。注册核对同时比较双标准和同标准的生产／hook 配置。

## 条件能力登记

| 能力 | 编译条件 | 注册与核对规则 |
| --- | --- | --- |
| `char8_t` | `defined(__cpp_char8_t) \|\| (defined(_MSVC_LANG) && _MSVC_LANG >= 202002L)` | 独立套件 `公共/条件/char8_t/便捷接口`；C++17 缺席，同一工具链与构建模式的 C++20/C++23 清单相同 |
| 128 位迭代器差值 | `defined(__SIZEOF_INT128__)` | 独立套件 `公共/条件/128位差值/抽样`；具备能力时两个版本注册相同用例；本地 MinGW 注册，MSVC 缺席 |

| libstdc++ 流填充异常 | `defined(__GLIBCXX__)` | 内部流格式用例中的实现检查；不参与公共注册清单比较 |
