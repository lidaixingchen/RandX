# 性能门禁验收记录

## 实现与验证范围

性能参数统一保存在 `tools/benchmark_policy.json`。`benchmark_gate.py` 生成冻结的运行计划，校验测量证据并决定门禁退出码、回归通知与基线发布资格；Actions 适配器负责查询和传递平台事实。常规基准、C++17 采样和 C++23 采样在三个独立 runner 上各自完成同机双边测量，由最终 `Benchmark` job 统一求值。

通用组保留双边各 5 次、每次最低目标 0.5 秒；两个采样组各保留双边 5 轮、最低目标 0.1 秒，以及疑点双边 6 轮、最低目标 1 秒的固定确认。容差均为 25%，严格大于容差才判定回归。生产头文件及算法来源没有变更。

本地使用 Miniconda 执行 72 项基准工具测试，全部通过；头文件生成检查通过，`benchmark.yml` 与 `ci.yml` 的 actionlint 检查通过。普通 CI 覆盖比较器、聚合、确认、门禁、Actions 适配和分组测量工具测试。

## 平台故障与刷新演练

演练在独立验证分支执行，完整用例清单与轮数保留，初测和确认计时目标缩短为 0.01 秒。这些运行用于验证平台执行语义，不用于性能收益比较。验证上下文关闭回归 issue 的写入资格。

| 场景与运行 | 观察结果 |
| --- | --- |
| [单组失败](https://github.com/lidaixingchen/RandX/actions/runs/36977707955) | 通用组的基线测量步骤以 failure 结束，完整 JSON 仍保留；两个采样 job 成功，最终报告保留通用比较证据与另外两组结果，以执行错误、退出码 2 失败 |
| [产物下载失败](https://github.com/lidaixingchen/RandX/actions/runs/36977712762) | 通用产物下载 outcome 为 failure，其 conclusion 经容错为 success；报告仍判定执行错误，另外两组完整结果保留，最终退出码 2 |
| [求值程序异常](https://github.com/lidaixingchen/RandX/actions/runs/36977718160) | 求值步骤抛异常，report_ready 和 exit_code 输出为空；最终退出步骤继续执行并返回 2，未通知、未发布 |
| [运行取消](https://github.com/lidaixingchen/RandX/actions/runs/36977723174) | 在三个测量 job 的构建阶段取消，最终 job 被取消；仅计划产物保留，测量、报告与基线发布均未继续 |
| [独立分支显式刷新](https://github.com/lidaixingchen/RandX/actions/runs/36978633859) | 策略目标设为验证分支，专用基线名称为 `benchmark-validation-baseline`；空历史记录进入 REFRESH，通用组测量候选，两个标准使用初始化采样提交完成双边测量；全部有效后由最终 job 成功上传专用产物 |

显式刷新演练调整初测原始输入以设置疑点，并保存调整记录。每个标准最终选择 3 项，按固定双边 6 轮执行真实确认，最终完整结果均通过；刷新报告的 publish_baseline 为 true、notify_regression 为 false。专用产物包含 `result.json`、`benchmark-gate.json` 和摘要，与生产基线名称分开。

错误或取消的四次运行均未生成任何基线产物。正常 PR 同样未发布生产基线。真实平台演练覆盖失败后的求值、诊断留存、字符串输出、跨 job 传输和最终退出条件。

## 决策契约与后续验收

单元测试覆盖容差边界、零基线、新增与缺失项、错误记录、重复 median、查询失败、完整记录选择、其他来源与失败运行排除、当前 run 排除、最新必要元数据缺失、空历史显式刷新、清单缺项、确认元数据及结果替换、跨组回归与错误并存、步骤原始 outcome、产物身份、取消、fork 通知资格、刷新回归豁免及发布条件。普通 master 手动比较不会发布；master push 和目标分支显式刷新需要全部有效结果及步骤成功才具备发布资格。

生产 master 的新工作流发布与显式刷新验收需要先合并 PR #11，再在 master 执行对应运行并记录运行链接及产物。当前证据证明 PR 比较、平台故障阻断和独立目标分支刷新发布；尚不能据此声称生产 master 的新发布路径已完成验收。

校准复用、统计阈值评估与长期性能参照按集中方案另行推进。
